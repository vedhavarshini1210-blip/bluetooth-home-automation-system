# Bluetooth Home Automation System

![Arduino](https://img.shields.io/badge/Arduino-Uno-blue?logo=arduino)

![License](https://img.shields.io/badge/License-MIT-lightgrey)

A Bluetooth-based Home Automation System developed using Arduino Uno that enables users to wirelessly control household appliances through a smartphone. The system also integrates Real-Time Clock (RTC) based scheduling to automate appliance operation, providing a simple, reliable, and energy-efficient home automation solution.

---

##  Project Objective

The primary objective of this project is to develop a low-cost and user-friendly home automation system that allows wireless control of electrical appliances using Bluetooth communication while supporting automatic time-based scheduling through an RTC module.

---

##  Technologies Used

### Hardware

* Arduino Uno
* HC-05 Bluetooth Module
* DS3231 RTC Module
* 4-Channel Relay Module
* Breadboard
* Jumper Wires
* Power Supply

### Software

* Arduino IDE
* Embedded C (Arduino Programming)

##  Getting Started

1. Clone this repository.
2. Open `bluetooth_home_automation.ino` using Arduino IDE.
3. Install the required Arduino libraries.
4. Connect the hardware as shown in the connection diagram.
5. Upload the program to Arduino Uno.
6. Pair the HC-05 Bluetooth module with your smartphone.
7. Open a Bluetooth terminal application and start controlling the appliances.
